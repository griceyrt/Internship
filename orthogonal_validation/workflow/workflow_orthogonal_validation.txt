ORTHOGONAL VALIDATION WORKFLOW
================================
Goal: Validate splicing events from the lab's manuscript (Nanopore long-read data,
      multiple timepoints) using public Illumina short-read RNA-seq data (GSE130613).
      If the same splicing events appear in both technologies, the finding is validated.

Dataset: GSE130613 (Manella & Asher, PNAS 2020) — normoxia DD controls, liver only
  NOTE: Both candidate datasets (GSE171975 and GSE130613) are MARS-Seq 3' end sequencing
        — not ideal for splicing but approved by Bharath. Low mapping rates documented.
  NOTE: Original authors used STAR + HTSeq-count on mm10. We use Salmon + mm39.

Comparison: Liver WT CT16-20 (n=4) vs Liver PerDKO CT16-20 (n=4) — constant darkness
  WT:     SRR9002567, SRR9002568, SRR9002569, SRR9002570
  PerDKO: SRR9002583, SRR9002584, SRR9002585, SRR9002586
  SRP accession: SRP194523

Reference genome: mm39 (GRCm39)
Custom transcriptome: transcriptome_ext.fa (provided by Khushi)
Custom GTF: transcriptome_productivity.gtf (in boundary_analysis/data/)


==============================================================================
TRACK 1 — SPLICING ANALYSIS
==============================================================================

--- SETUP [BASH] -------------------------------------------------------------

STEP 1 — Download raw FASTQ files from SRA
  8 samples, SINGLE-end (MARS-Seq 3' end sequencing)
  Script: scripts/get_sra_dump_fastq_run_salmon.sh
  Tools: prefetch + fasterq-dump (sra-tools)
  Output: temp/<SRR>.fastq.gz

STEP 1b — Adapter trimming (cutadapt)
  Added 2026-06-18 per Bharath's email (GEO metadata states cutadapt was used)
  Adapter: AGATCGGAAGAGCACACGTCTGAACTCCAGTCA (standard Illumina TruSeq Read 1)
  Flags: --minimum-length 20
  Output: temp/<SRR>_trimmed.fastq.gz
  NOTE: Tested on SRR9002567 — improvement from 56.71% to 60.55% (modest).
        Decision on rerunning all 8 samples pending Bharath's response.

STEP 2 — Build Salmon index (once, already built)
  Input: transcriptome_ext.fa + mm39 genome FASTA
  Build gentrome_ext.fa (transcriptome + genome concatenated) and decoys.txt
  Command:
    salmon index -t data/gentrome_ext.fa \
                 -i data/transcriptome_ext_index \
                 --decoys data/decoys.txt \
                 -k 31 --keepDuplicates
  Index location: data/transcriptome_ext_index/

--- SALMON [BASH] ------------------------------------------------------------

STEP 3 — Salmon quantification (all 8 samples)
  Script: scripts/get_sra_dump_fastq_run_salmon.sh SRP194523 data/transcriptome_ext_index
  Mode: quasi-mapping, single-end (-r flag), library auto-detect (-l A)
  Salmon detected: -l U (unstranded) — confirmed correct (compatible_fragment_ratio=1.0)
  Flags: --seqBias --gcBias
  Output: results/SRP194523_salmon_<date>/<SRR>/quant.sf (8 files)

  Mapping rates (original, untrimmed):
    SRR9002567 WT:     56.71%
    SRR9002568 WT:     57.22%
    SRR9002569 WT:     70.17%  (outlier)
    SRR9002570 WT:     56.89%
    SRR9002583 PerDKO: 47.26%
    SRR9002584 PerDKO: 46.62%
    SRR9002585 PerDKO: 43.82%
    SRR9002586 PerDKO: 47.54%

  Low rates documented as expected for MARS-Seq 3' end data + custom transcriptome.

  *** BRANCHING POINT ***
  -> Track 1 continues at STEP 7
  -> Track 2 starts at STEP 5a (run Steps 5a–6 in parallel)

--- SPLICING ANALYSIS USING SUPPA [BASH / PYTHON] ---------------------------

STEP 7 — generateEvents from GTF
  suppa.py generateEvents -i transcriptome_productivity.gtf \
                          -o results/suppa_<date>/transcriptome_ext \
                          -f ioe -e SE SS MX RI FL -b S
  Output: IOE files (SE, A3, A5, MX, RI, AF, AL)
  Boundary: -b S (strict) — confirmed by manuscript and Khushi

STEP 8 — Compile expression table for SUPPA
  Input: normalised expression table from Step 5c (NOT raw Salmon TPM)
  Output: results/normalisation/combined_norm.tab
  NOTE: Batch correction SKIPPED — no batch info available for GSE130613 DD samples

STEP 9 — psiPerEvent
  suppa.py psiPerEvent -i <event.ioe> \
                       -e combined_norm.tab \
                       -o results/suppa_<date>/
  Output: .psi files per event type

STEP 10a — Split PSI and expression table by condition
  *_WT.psi       (SRR9002567–70)
  *_KO.psi       (SRR9002583–86)
  WT_norm.tab
  KO_norm.tab

STEP 10b — diffSplice (WT vs PerDKO)
  suppa.py diffSplice --method empirical \
                      --input <event.ioe> \
                      --psi *_WT.psi *_KO.psi \
                      --tpm WT_norm.tab KO_norm.tab \
                      -gc -o results/suppa_<date>/diff/diff_<EVENT>
  Output: diff_*.dpsi.temp.0
  Significance filter (Illumina): |dPSI| > 0.1 AND p < 0.3
    NOTE: relaxed from 0.05 — low power at n=4 replicates with empirical method
  Sign convention: dPSI in output file = WT - KO; negated in plots to show KO - WT


==============================================================================
TRACK 2 — DIFFERENTIAL EXPRESSION
==============================================================================

--- NORMALISATION [R] --------------------------------------------------------

STEP 5a — Import Salmon output into R
  Script: scripts/normalisation_deseq2.R
  tximport reads all 8 quant.sf files (transcript-level)
  tx2gene built from transcriptome_productivity.gtf

STEP 5b — Filter
  Keep transcripts with >5 counts in ≥2 samples
  155,263 → 20,754 transcripts retained

STEP 5c — Normalize
  counts / total reads per sample
  Output: results/normalisation/combined_norm.tab  (SUPPA input)

--- DESEQ2 [R] ---------------------------------------------------------------

STEP 6 — DESeq2 differential expression
  Run DESeq2 on raw tximport counts (NOT normalized values)
  Significance: |log2FC| > 0.5 AND padj < 0.05  (Kiran's decision, finalized 2026-06-18)
  Output: results/normalisation/deseq2_KO_vs_WT.tsv
  343 significant DE genes
  -> Feeds into Step 13 (DE volcano) and Step 14 (DE vs splicing Venn)
